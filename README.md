# AI 档案库 · Chris Song

> 这是 Chris（宋孝臣）所有 AI 助理共用的**记忆与规则真源**。
> 任何 AI 接手工作前，先读这里，再动手。

## 这个仓库解决什么问题

多个 AI（Hannah / Nova / 小龙虾 / 未来的任何模型）各自有记忆，但**互相看不见**：
同一个客户被问三遍、同一条红线被踩三次、同一份报价被重算三次。

这里把所有**该记住的东西**放进一个版本化的仓库，每个 AI 开工前 `git pull`，
收工后 `git push`。记忆从此只有一份。

## 什么**不**在这个仓库里（重要）

| 不进 | 原因 |
|---|---|
| `敏感-个人证件/`、`敏感-凭据/` | 隐私与合规 |
| `高风险-GPU服务器/` | Chris 明确要求隔离 |
| 合同/发票/证件原件（pdf/docx/xlsx） | 体积大 + 含商业机密 |
| 邮件原始库（2.5 万封） | 体积 + 客户隐私 |
| 知识库原始语料（420MB） | 用本地 RAG，不上云 |
| 任何密码、API Key、授权码 | 只放 `~/.hermes-secrets/`，权限 600 |

> 判断标准：**这段文字如果被竞争对手看到，会不会伤到 Chris？** 会 → 不进。

## 怎么用（每个 AI 的开工/收工程序）

```bash
# 开工
git pull --rebase

# 读到新的事实、新的红线、新的客户规律 → 写进对应文件
# 收工
git add -A && git commit -m "update: <今天学到什么>" && git push
```

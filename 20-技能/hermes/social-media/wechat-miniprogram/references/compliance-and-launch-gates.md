# 微信小程序合规与上架闸门（数字速查）

评估任何小程序项目前先读这个文件。**数字核查于 2026-10**；微信政策变动频繁，凡要对外报价、承诺周期或写进合同的数字，先回官方页复核。原则：查不到官方来源就不写数字。

## 一、三道闸门

| 闸门 | 内容 | 谁做 | 周期 |
|---|---|---|---|
| 类目与资质 | 按实际功能选服务类目，部分类目要许可证（见 §2） | 用户提供资质，我提交 | 类目审核 1–3 天；办许可证 1–3 个月 |
| ICP/APP 备案 | 小程序本体必须备案后才可上架；需主体证件 + 法人/负责人核验（人脸/短信），备案「服务内容标识」选错要返工 | 我操作，用户核验 | 数日至 20 工作日 |
| 支付通道 | 虚拟商品必须接入小程序虚拟支付（见 §3） | 我接入，用户提供主体资料签约 | 开通审核 1–7 工作日 |

云开发可省掉「域名备案」，但**省不掉小程序自身的备案**。

## 二、类目与资质

| 类目 | 资质要求 |
|---|---|
| 社交-陌生人交友 / 社交-熟人交友 / 社交-婚恋 | 《增值电信业务经营许可证》（ICP 经营许可证，核准含「互联网信息服务业务」）。该证要求内资公司、注册资本门槛（通常 ≥100 万）、社保人员等，代办 1–3 个月、万元级 |
| 工具（信息查询 / 办公 / 计算器 / 效率等） | 一般只需营业执照（企业/个体户）或无需额外资质 |
| 生活服务-电子娱乐服务 | 《营业执照》经营范围含「互联网游戏服务」或「动漫游戏开发」相关 |
| 教育-在线视频课程（其他） | 营业执照 + 《非经营性互联网信息服务备案核准》或含「互联网信息服务业务」的《增值电信业务经营许可证》 |

判类目的实操：类目按**实际功能**判，不按自我宣称。想走轻合规，就把产品做成工具（私密、双人、无公开内容、无陌生人匹配），并在界面文案层面贯彻；想做社交平台，先备 ICP 许可证。

官方类目总表：https://developers.weixin.qq.com/miniprogram/product/material/
社交-交友资质页：https://developers.weixin.qq.com/miniprogram/product/material/shejiao/jiaoyou.html

## 三、支付通道（虚拟商品）

官方判定：小程序内的虚拟商品（虚拟货币、**解锁功能**、订阅内容、付费功能、打赏、虚拟礼物）必须接入**小程序虚拟支付**，不得引导至 App / 公众号 / H5 / 个人号 / 网站完成支付。典型须全终端接入的形态包括：音视频内容、小说漫画、在线课程、游戏工具与陪玩、**陌生人交友/相亲社交**、摄影修图等效率工具。

| 项 | 企业 / 事业单位 / 个体工商户 | 个人主体 |
|---|---|---|
| 开通条件 | 已认证小程序 + 上述主体类型 | 工具类目 + 已完成认证与备案 |
| 能力 | 道具直购 / 代币 | 仅道具直购（不引入代币） |
| 收款限额 | 按主体与类目 | 月收款限额约 10 万元 |

费率与结算：

- Android / 鸿蒙 / Windows：微信支付通道，平台技术服务费约 **1%**，**T+3** 结算（先冻结后分账），到账可提现。
- iOS：走 **Apple 支付（IAP）**，苹果佣金约 **12%**，结算周期 **45–60 天**；额外条件：小程序需配置简称（display name）、用户 iOS 15+、微信客户端 8.0.68+、单笔最低 1 元、仅大陆 App Store 账户。Apple 支付不支持沙箱。
- 退款：支付 180 天以内的退款平台退还手续费，超过不退。

开通后后台给出 AppID / OfferID / AppKey（分沙箱与现网），服务端调 `/xpay/*` 接口用 appkey 做 `pay_sig`（HMAC-SHA256，uri 不带参数、post_body 与真实 HTTP 请求完全一致）+ 用 session_key 做 `signature`；客户端调 `wx.requestVirtualPayment`，平台按设备类型自动路由到微信支付或 Apple 支付。发货至少实现「消息推送」与「轮询查单」之一（两者都用最可靠）；订单状态以服务端 `query_order` 为准。

官方文档：
- 企业/个体户开通：https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html
- 个人主体：https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment/person.html
- 虚拟支付业务运营指南（管控类目与场景判定）：https://developers.weixin.qq.com/community/minihome/doc/00002cf077cd4810fee42f4b865c01

## 四、小游戏（若真要做游戏）

有内购/变现的小游戏必须有**游戏版号**：企业主体（个人与个体工商户都不行）、注册资本 ≥100 万、需 ICP 资质，版号全流程 3–6 个月。小游戏另有内容备案（含截图、玩法说明，名称与主体须全程一致，否则驳回）。

参考：https://developers.weixin.qq.com/minigame/product/material/ ｜ 版号周期与门槛：https://cloud.tencent.com/developer/news/3536187

## 五、备案（小程序自身）

2023-09 起未备案不得上架；备案需工信部短信核验，24 小时内未核验成功会被自动驳回、需重新发起。备案「服务内容标识」要与实际功能一致（工具类选信息查询/相应工具项），选错会驳回返工。

官方指引：https://developers.weixin.qq.com/miniprogram/product/record/guidelines

## 六、云开发成本

- 免费体验环境：新账号可开一个，约 4 万资源点/月，体验 6 个月；仅体验阶段免费（发布上线后需续费/付费）。
- 基础套餐：约 **¥19.9/月**（原价 ¥39/月），含 20 万次调用、2GB 容量、5GB CDN 流量等；超量按量付费。
- 另有微信云托管（按量计费，先充后用）可选。

价格计算器：https://cloud.weixin.qq.com/cloudbase/price

## 七、名称与内容

- 小程序名称全网唯一，命中关键词需提交证明材料并审核（可用商标等证明）。名句/热词命名的名称大概率已被占用。
- 平台无占卜/算命/风水类目；「相遇指数」「缘分」这类娱乐化结果必须明确标注仅供娱乐，措辞避开测算/占卜/算命，避免被拒或下架。
- 个人信息采集（位置、时间、身份关系等）须在《用户隐私保护指引》中声明后采集，未声明调用会被驳回。

# 囤货/倒卖交易的形势分析与决策

回答「要不要囤、预期能不能卖出去、这笔做不做」。典型触发：Chris 给一个采购报价（甚至说要贷款去收货），
要求「分析形势 / 出分析报告」。交付物是一份能直接拿去做决策的中文报告，不是行情综述。

## When to Use

- 「××卡/内存/硬件 深圳采购，囤货卖货的预期销售，帮我分析形势」。
- 拿到具体报价（单价、数量、含税口径、货源）后判断这个价能不能接。
- 卖方随后发来采购合同、或合同前阶段的《采购函》+《库存清单》+配置单资料包：条款、缺附件、配置口径与对手方风险走
  `trade-quotation-and-agency-agreement`（合同前资料包见其 `references/supplier-quotation-package-review.md`），
  本技能只管价格与决策，两条线分别出稿、互相引用结论。
- Not for：纯行情资讯整理；一次性「现在多少钱」（直接检索回答即可）。

## 交付物与格式（硬性偏好）

- 中文，**结论先行**：第一段就给出「能做／不能做／怎么做」，不要背景铺垫开场。
- **只发纯文本文件**：报告、合同、清单一律 `.md`（必要时附 `.txt`）发给 Chris；**不要发 .docx/.xlsx/.pptx 等二进制附件，他认为那是打不开的二进制的文件**。docx 只能是内部中间产物（需要盖章/打印时再另存），聊天里交付的永远是文本。
- 报告落盘 `~/AI工作台/<项目名>/<主题>-<YYYYMMDD>.md`；聊天里只给精简版：结论 → 关键数字表 →
  必做清单 → 风险红线。不复述检索过程。
- 报告结构固定：①一句话结论 ②价格锚点表（每个数字带日期与来源）③对报价的定位（比市场贵/便宜多少）
  ④驱动力与反证（事实与传闻分开）⑤资金与盈亏模型 ⑥三层风险 ⑦建议分档 ⑧必做动作清单
  ⑨未来 N 周观察点日历 ⑩未能核实的信息。
- 表优于段落；单价、总价、比值、盈亏都用 `execute_code` 算出来再写（不心算）。
- 事实（有来源有日期）与传闻（官方未确认）必须分开标注，传闻不得当结论使用。

## 流程

1. **先锁标的，再谈价格**：同系列不同容量/版本的 SKU 价差可达数倍，同名不等于同一件货。
   报告单列一节写 SKU 歧义：报价对应哪个型号/容量/包装，以及不同假设下「贵还是便宜」如何完全翻转。
2. **建价格锚点表**：国内街价、平台挂牌价、回收/批发成交价（三个口径分别列）、海外同款折人民币
   （实时汇率，标注时间）、首发 MSRP/官方指导价、一年前价格、求购侧出价。来源与口径见
   `references/cn-hardware-price-sources.md`。
3. **判断套利方向**：把各市场折成人民币排一排。若国内最贵，则「外购内销」的流入方向成立、出口套利不成立——
   这一步会否掉一整套方案，必须先算。
4. **供需驱动清单 + 反证**：产能/停产（传闻一律标「官方未确认」）、政策（进口许可、出口管制审批口径变化）、
   替代品时间表（下一代、减配版）、上游成本周期（存储/晶圆合约价）。每条带日期与来源。
   同时列反证：现货端是否已在回落、补贴与促销节奏、终端价格承受力（卖不动就是见顶前兆）。
5. **资金与盈亏模型**：本金、资金成本（利率×持有月数）、仓储安保保险验货、盈亏平衡卖价、情景表
   （价格 +30/+15/0/−10/−20/−30%）与 ROI。公式与代码模板见 `references/deal-economics-model.md`。
   GPU 整机/IDC 硬件的跨境单直接用 `~/.nova-tools/gpu_deal.py` 跑（含运费/保险/关税/增值税/融资/汇率差/持有），
   必须出**年化 ROI、保本单台售价、保本汇率与敏感性表**；只报毛利率等于没算资金占用与汇率。
6. **现金流锚**：用该资产的租金/产出收益反推价格有没有底。若租金不随售价同步上涨，说明现价由缺口与
   囤货预期定价、没有现金流托底——这是判断「贵得离谱」最硬的一条证据。
7. **三层风险逐层写**：
   - 合规：货源合法性（走私/无进口凭证）、出口管制与转口（**不给任何规避方案**）、
     **我方公司主体必须完全隔离**——货代的报关资质、AEO、公司信用不能被这类货的资金流/货物流/票流牵连。
   - 对手方：走 `trade-quotation-and-agency-agreement` 的核验流程（USCC 校验位、对公户名、工商四项、凭证）。
     「高价 + 含税 + 大批量 + 陌生主体 + 要求预付」是钓鱼报价的标配组合。
   - 流动性：下跌时灰度货源没有承接、无票货进回收池再折价、货值大导致安保与保险成本（无票货通常无法正常投保）。
8. **杠杆纪律**：信贷资金不得流入投机领域（一经查实提前收贷），而抽贷时点往往正是货砸手里的时点。
   给出额度上限（≤自有可支配资金 30–50%）、期限覆盖最坏持有期、不用公司主体或公司资产抵押、
   留出能独立偿付利息的现金。
9. **建议分档，不要用「注意风险」收尾**：
   - 不建议：裸囤（尤其借贷）；
   - 可做的降杠杆结构：背靠背（先锁下游定金再提货、赚单次差价快速周转）、撮合/代采（赚佣金不持货）、
     小批试水（首单 ≤10–20 件跑通全流程）；
   - 替代标的：集团内更合规、更容易开票的品类（整机/服务器集成、标准化存储器件）。
   - 执行纪律：止损线（跌破成本 X% 无条件清仓，不加仓不摊平）、止盈分批、单笔敞口上限。

## 常设业务规则

- 合规优先于利润：出口管制/转运规避类交易不做、不给规避方案，发现风险先提示。
- 钱、贷款、合同、印章、对外发送：只出稿与建议，执行前逐次经 Chris 确认，零自动发送。
- 不编造：查不到的事实写「未能核实」并列入待办；对方报价不等于市场价；传闻不写成事实。

## Pitfalls

- **把挂牌价当成交价**：挂牌是要价，批发与回收端的可执行价通常低一档，下跌时干脆停收。
  必须用成交侧价格重算，否则会把「进场即倒挂」的报价当成进货价（判成「略贵」，实际贵 10% 以上）。
- **用 MSRP/官方指导价判断贵贱**：现货可与指导价脱节数倍，指导价只能当历史参照。
- **把停产/断供传闻当已确认事实**：传闻推涨时，那段涨幅本身就是传闻溢价，落空或辟谣会先回吐这一段。
- **只算资金成本、不算价格波动**：3% 年化的持有成本，3 个月约 1%，而这类标的单周可波动 ±10%；
  风险几乎全在价格上，报告要把这一点说破，否则「资金成本才 1%」会被误读成安全。
- **忽略物理与安保**：几百件货是上吨的体积与重量，需要独立库房、安保、防潮防静电，另有失窃风险。
- **忘了公司主体隔离**：把这类货的货款、仓储、运输接进自己的货代公司，等于拿报关资质和银行授信去赌。
- **报告只讲方法不给数字**：Chris 要的是算好的账与结论，不是分析框架或风险清单。
- **只报毛利率，不报年化**：硬件单毛利率常见只有 5–8%，看着薄；但资金一年能转 3–4 次，年化才是真挣的。
  反过来，售价跌 5% 就能把这 8% 吃光——所以年化与敏感性必须同时给，缺一个就会把「能做」判成「赚」。
- **发二进制附件**：文档交付默认纯文本。用 docx 工具生成过合同/报告时，必须 `docx_cjk.py export` 导出 `.md`+`.txt` 并优先发文本版，不要把 `.docx` 当成交付物。

# 囤货盈亏模型（公式与代码模板）

用 `execute_code` 跑，数字进报告；不要心算。

## 公式

```
本金          = 单价 × 数量
资金成本      = 本金 × 年利率 × 持有月数 / 12
持有杂费      = 单件每月杂费 × 数量 × 持有月数     # 仓储、安保、保险、验货人工
盈亏平衡卖价  = 单价 + (资金成本 + 持有杂费) / 数量
情景出场价    = 单价 × (1 + 涨跌幅) − 出货让价     # 出货让价：批发/回收口径，常见 3%–15%
盈亏          = (出场价 − 盈亏平衡卖价) × 数量
ROI           = 盈亏 / 本金
```

现金流锚（用租金/产出反推价格有没有底）：

```
单件月毛收益 = 资产市面月租 / 件数（或 单位时间产出 × 单位时间）
年化毛回报   = 单件月毛收益 × 12 / 单价
回本年限     = 单价 / 单件月净收益        # 净 = 毛 − 电费/托管/运维/空置率
```

## 代码模板

```python
def model(n, buy, months, rate, ops_per_card_month, exit_mult, exit_haircut=0.0):
    cap = n * buy
    fin = cap * rate * months / 12
    ops = ops_per_card_month * months * n
    breakeven = buy + (fin + ops) / n
    exit_price = buy * (1 + exit_mult) - buy * exit_haircut
    pnl = (exit_price - breakeven) * n
    return dict(本金=cap, 资金成本=fin, 持有杂费=ops,
                盈亏平衡卖价=round(breakeven), 出场价=round(exit_price),
                盈亏=round(pnl), ROI=round(pnl / cap * 100, 1))

for m in (0.30, 0.15, 0.0, -0.10, -0.20, -0.30):
    print(f"{m:+.0%}", model(100, 56500, 3, 0.03, 300, m))
```

## 报告里必须出现的四个数

1. **盈亏平衡卖价**及其对应的「需要涨多少 %」——往往只有几个百分点，先破除「涨一点就赚」的错觉。
2. **横盘（0%）情景的盈亏**——横盘即亏，这是杠杆的代价，写出来比讲道理有效。
3. **下行 −20%/−30% 情景的绝对亏损额**——用金额（万元级）写，不用百分比。
4. **资金成本 vs 价格波动的量级对比**——例如资金成本 3 个月约 1%，而历史单周波动 ±10%。

## 灵敏度两档

- 出货口径至少算两档：有票（走大客户/整机商，让价小）与无票（回收池，让价 10–15%，且失去进项抵扣）。
- 两档的结论方向可能相反——这正是「报价能不能接」取决于下游客户结构的原因。

```

       + 融资((货值+运费)×年利率×融资天数/365) + 持有(货值+运费×0.6%/月×持有天数/30)
年化ROI = ROI × 365 / (融资天数 + 持有天数)
保本单台售价 = 总成本(RMB) / 卖出汇率 / 数量
保本汇率     = 总成本(RMB) / 收入(USD)
```

必须同时给出的四个数：**年化 ROI、保本单台售价、保本汇率、售价±10%×汇率±0.10 敏感性表**。

- **汇率是隐形杀手**：买入价与卖出价差 0.5%（如 7.12 买 / 7.06 卖）就吃掉半个毛利；保本汇率一算出来，很多「看着能赚」的单直接否掉。
- **判据**：年化 <25%，或售价 −5% 就归零 → 不做。实测一单 H200×4、加价 11%、毛利率 7.2%、年化 27.9%，售价 −10% 变成年化 −15.5%（亏六位数美元）。
- **铁律：先锁买家再锁货。** 这类货薄利高杠杆，没有 offtake/定金不持货；囤货只在有明确下游承接时做。

# 硬件/显卡类商品的价格来源与口径

做囤货分析与长期盯价时用这份清单取数。三条总口径先记住：

1. **要价（挂牌）、成交（批发/回收）、历史参照**分开列，不混用。
2. **同名不同容量/版本价差可达数倍**（例：同系列 32G 版本与 24G 减配版），报告里必须锁定 SKU。
3. **「有价无货」写进报告**：涨价行情里挂牌价含缺货注水，货源状态本身就是信息。

## 国内（中文源）

| 来源 | 给什么 | 怎么用 |
|---|---|---|
| 每日行情播报（显卡日报类，B 站/知乎/资讯站转载） | 型号「报价」、街价、日涨跌 | 看趋势与日波动幅度；报的是报价，不是成交 |
| 什么值得买「行情对账」型长帖 | 把补贴、Q4 合约价、多市场、二手、回收交叉对一遍 | 抓变量（促销补贴是否回归/下架）最有效 |
| 走访报道（36氪、时代周报、21 财经、上海证券报、南方都市报） | 区间价 + 商户原话 | 商户原话（「卖不动」「不敢囤」「一天一个价」）是需求端证据，可直接引用 |
| 行业群/算力群的「求购·收货·出货」消息 | **真实买盘出价** | 「找 N 片 XX、含税 X 以上、现货秒款」＝可执行买价，判断成交侧最硬的公开证据 |
| 电商平台（京东/淘宝/天猫）与旗舰店 | 挂牌价、缺货状态、促销补贴 | 只在标注口径后使用；旗舰店「即将售罄」本身是信号 |
| chiphell / 知乎 / 贴吧 全球比价帖 | 同一型号各国价格并列 | 快速定位哪个市场最贵/最便宜 |

## 海外（英文源）

- **逐日价格序列**类追踪站（例：pctechvault 的 daily median，标注税口径与采集点）——做趋势图与「一年涨 132%」这类量化结论的首选。
- Tom's Hardware / TechPowerUp / Tom's Guide ——停产与泄漏传闻（要标注「官方未确认」）。
- gpudeals / eBay 成交 ——美国最低现货与二手成交两侧。
- 日本、德国当地媒体报道 ——当地零售与二手成交价（日本二手成交价常是亚太参照）。

## 现金流锚（判断价格有没有底）

- 云算力平台公开价目（元/卡/小时、整机月租）——反推单卡月毛收益。
- 行业资讯平台的算力成交通报（成交价 vs 报价）——租赁端是否在松动。
- 判据：**租金不随售价同步上涨 ⇒ 现价由缺口与囤货预期定价，没有现金流托底。**

## 汇率与税收口径

- 实时汇率用 `open.er-api.com/v6/latest/USD` 或 frankfurter，取数时写时间戳。
- 海外价标注含税/不含税（欧洲多含 VAT，美国多不含税）；国内区分「含税（专票）」「不开票」。
  含票溢价是真实存在的（能进大客户采购流程），无票货只能进回收池、再让价一档。
